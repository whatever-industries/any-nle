# Any NLE Resolve templates

These are self-authored project data for Any NLE's 1920×1080, 23.976 fps
Avid-to-Resolve route. They were exported from new projects in DaVinci Resolve
Studio 21.2.0 build 00006, project version 17. Layout supplies the project
and standalone media records. Atom supplies the split-MXF media record.
Group supplies the editable two-camera Group and OP1a records.

The authoring projects used only locally generated test patterns, solid
colors and PCM tones. Resolve exported the projects without stills or LUTs.
The preparation pass replaced media directories with synthetic placeholders
and cleared working directories and stored previews, including thumbnails
in sequence metadata. The shipped archives contain project XML and serialized
project settings. The original generated media is outside the package.

Each neighboring SHA-256 pin identifies the exact reviewed archive.
The content review checked archive members, XML and decoded settings and
cache payloads for media, preview images, external LUTs, script or executable
payloads and machine-local locators.

The installed Resolve license assigns exported user content to its
applicable owner and reserves rights in the software. This review is
specific to these three self-authored archives. Blackmagic Design software
and its bundled assets are outside this package. [Blackmagic reference manual](https://documents.blackmagicdesign.com/UserManuals/DaVinciResolveReferenceManual.pdf)
